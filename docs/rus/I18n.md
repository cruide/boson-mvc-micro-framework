# Документация класса `I18n` (Boson Framework)

Система интернационализации. Singleton, загружает переводы из PHP-файлов, поддерживает плейсхолдеры и fallback к базовому языку.

## Файлы переводов

Расположены в `app/lang/{lang}.php`. Возвращают ассоциативный массив:

```php
// app/lang/ru.php
return [
    'welcome'    => 'Добро пожаловать',
    'hello_user' => 'Привет, :name!',
    'items_count'=> ':count товаров',
];
```

Ключи должны быть валидными именами переменных (`[a-zA-Z_][a-zA-Z0-9_]*`).

## Использование

### Глобальная функция `i18n()`

```php
// Строка без параметров
echo i18n('welcome');                    // "Добро пожаловать"

// Строка с плейсхолдерами
echo i18n()->get('hello_user', ['name' => 'Иван']);  // "Привет, Иван!"

// Если ключ не найден — возвращается ::key::
echo i18n('nonexistent');                // "::nonexistent::"
```

### Плейсхолдеры

Формат: `:name` в строке перевода. Заменяются значениями из массива:

```php
// app/lang/ru.php
'greeting' => 'Здравствуйте, :name! Ваш баланс: :balance руб.',

// Использование
i18n()->get('greeting', ['name' => 'Алекс', 'balance' => 1500]);
// "Здравствуйте, Алекс! Ваш баланс: 1500 руб."
```

## Выбор языка

Приоритет определения текущего языка:
1. Cookie `lang` (установленная пользователем)
2. `config.ini`: `lang = ru`
3. Язык по умолчанию: `en`

```php
// Установить язык вручную (сохраняется в cookie)
i18n()->setCurrentLang('ru');

// Узнать текущий язык
$lang = i18n()->getCurrentLang();  // "ru"

// Язык по умолчанию
$default = i18n()->getDefaultLang();  // "en"

// Список доступных языков (только те, для которых есть файлы)
$available = i18n()->getLanguages();  // ['en' => 'English', 'ru' => 'Русский', ...]
```

## Поддерживаемые языки

В классе предопределены: `en`, `ru`, `ua`, `be`, `de`, `fr`. Фактически доступны только те, для которых существует файл в `app/lang/`.

Чтобы добавить новый язык — создайте файл `app/lang/es.php` и добавьте код в массив `$languages` внутри класса, либо расширьте его.

## Fallback

Если ключ отсутствует в текущем языке — ищется в языке по умолчанию (`en`). Если и там нет — возвращается `::key::`.

## Особенности

- Файлы переводов кэшируются (загружаются один раз)
- `strtr` используется для замены плейсхолдеров (быстрее `str_replace`)
- Имена ключей валидируются (`isVariableName`)
- Текущий язык сохраняется в cookie `lang`

## Ручной доступ

```php
$i18n = \Boson\I18n::getInstance();
$i18n->setCurrentLang('de');
echo $i18n->get('welcome');
```
