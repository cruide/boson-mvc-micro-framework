# Документация класса Boson\Native (Boson Framework)

Класс `Native` представляет собой легкий шаблонизатор, входящий в состав фреймворка Boson. Он позволяет рендерить PHP-шаблоны (`.phtml`), передавать в них переменные и поддерживает базовую коррекцию XHTML. API частично совместим со Smarty для упрощения миграции.

## Инициализация

Для работы классу требуется указать директорию, в которой хранятся файлы шаблонов. Директория должна существовать.

```php
use Boson\Native;
use Boson\NativeException;

try {
    $tpl = new Native('/path/to/templates/');
} catch (NativeException $e) {
    echo "Ошибка инициализации: " . $e->getMessage();
}
```

**Константы класса:**
*   `Native::EXTENSION` — расширение файлов шаблонов по умолчанию (`'phtml'`).
*   `Native::XHTML_CRRECTION_ON` — включить коррекцию XHTML.
*   `Native::XHTML_CRRECTION_OFF` — выключить коррекцию XHTML.

## Переменные шаблона

### Локальные переменные (`assign`)

Переменные, назначенные через `assign`, доступны только в текущем экземпляре класса.

**Метод:** `assign($name, $value)`

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `$name` | string / array | Имя переменной или массив данных. |
| `$value` | mixed | Значение переменной. Если `$name` — массив, этот параметр игнорируется. |

**Особенности:**
*   Поддерживает цепочку вызовов (возвращает `$this`).
*   Если передать `null` в качестве значения, переменная будет удалена.
*   Если передать массив в `$name`, произойдет массовое присваивание.

```php
// Одиночное присваивание
$tpl->assign('title', 'Главная страница');

// Массовое присваивание
$tpl->assign([
    'user' => 'Alex',
    'role' => 'admin'
]);

// Удаление переменной
$tpl->assign('temp_var', null); 

// Цепочка
$tpl->assign('a', 1)->assign('b', 2);
```

### Глобальные переменные (`setGlobal`)

Переменные, назначенные через `setGlobal` (или `assignGlobal`), являются статическими и доступны во всех экземплярах класса и шаблонах.

**Метод:** `setGlobal($name, $value)` (статический)
**Метод:** `assignGlobal($name, $value)` (экземпляр, для совместимости)

```php
// Установка глобальной переменной
Native::setGlobal('site_name', 'My Website');

// Массовое глобальное присваивание
Native::setGlobal([
    'version' => '1.0',
    'copyright' => '2023'
]);

// Удаление глобальной переменной
Native::setGlobal('old_config', null);
```

## Рендеринг

### `fetch` (получить строку)

Обрабатывает шаблон и возвращает результат в виде строки. Не выводит ничего в браузер.

**Сигнатура:** `fetch($file_name, $need_ext = true, $xhtml = Native::XHTML_CRRECTION_OFF)`

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `$file_name` | string | Имя файла шаблона. |
| `$need_ext` | bool | Автоматически добавлять расширение `.phtml`, если его нет. |
| `$xhtml` | bool | Включить коррекцию XHTML для этого вызова. |

```php
$content = $tpl->fetch('index.phtml');
// Сохранить в файл или передать в другой шаблон
file_put_contents('cache.html', $content);
```

### `display` (вывод сразу)

Обрабатывает шаблон и сразу отправляет результат в вывод (echo). Также отправляет заголовки приложения (через внешнюю функцию `send_header_app_info()`).

**Сигнатура:** `display($file_name, $xhtml = Native::XHTML_CRRECTION_OFF)`

```php
// Вывод шаблона в браузер
$tpl->display('index.phtml');
```

## XHTML Коррекция

Класс содержит встроенный механизм исправления распространенных ошибок XHTML (добавление кавычек к атрибутам, закрытие тегов и т.д.).

*   По умолчанию выключена (`XHTML_CRRECTION_OFF`).
*   Можно включить глобально через `Native::$correctXHTML = true;`.
*   Можно включить для конкретного вызова `fetch` или `display`.

**Что исправляет:**
*   Атрибуты без кавычек: `width=100` → `width="100"`
*   Теги без закрытия: `<br>` → `<br />`, `<img src="...">` → `<img src="..." />`
*   Лишние пробелы вокруг `=` и `>`.

## Примеры использования

### 1. Базовый сценарий

**PHP:**
```php
<?php
require_once 'Native.php';
use Boson\Native;

$tpl = new Native(__DIR__ . '/views/');

$tpl->assign('page_title', 'Контакты');
$tpl->assign('email', 'support@example.com');

$tpl->display('contacts.phtml');
```

**Шаблон (views/contacts.phtml):**
```html
<h1><?= $page_title ?></h1>
<p>Свяжитесь с нами: <?= $email ?></p>
```

### 2. Использование глобальных переменных

Полезно для передачи данных, общих для всех страниц (например, путь к сайту, версия).

**PHP:**
```php
<?php
use Boson\Native;

// Устанавливаем один раз при старте приложения
Native::setGlobal('base_url', 'https://mysite.com');
Native::setGlobal('year', date('Y'));

$tpl = new Native('./templates/');
$tpl->assign('content', 'Текст страницы');

// В шаблоне доступны и $content, и $base_url, и $year
$tpl->display('layout.phtml');
```

### 3. Включение XHTML коррекции

Если требуется строгое соответствие стандартам.

**PHP:**
```php
<?php
use Boson\Native;

$tpl = new Native('./templates/');
$tpl->assign('width', 100);

// Включаем коррекцию только для этого вызова
$html = $tpl->fetch('table.phtml', true, Native::XHTML_CRRECTION_ON);

echo $html;
```

**Шаблон (table.phtml) - "Грязный" HTML:**
```html
<table width=<?= $width ?> cellpadding=5>
  <tr><td>Ячейка</td></tr>
</table>
<br>
```

**Результат после коррекции:**
```html
<table width="100" cellpadding="5">
  <tr><td>Ячейка</td></tr>
</table>
<br />
```

### 4. Обработка ошибок

```php
<?php
use Boson\Native;
use Boson\NativeException;

try {
    $tpl = new Native('/non/existent/path/');
} catch (NativeException $e) {
    // Логирование ошибки
    error_log($e->getMessage());
    echo "Система временно недоступна.";
}
```

## Технические требования и примечания

1.  **Внешние зависимости:** Класс использует функции `path_correct()` и `send_header_app_info()`. Убедитесь, что они определены в вашем окружении перед использованием класса `Native`.
2.  **Безопасность:** Класс использует `include` для рендеринга. Не передавайте пользовательский ввод напрямую в имена файлов шаблонов без санитизации.
3.  **Очистка свойств:** Метод `flushProperties()` предназначен для очистки назначенных переменных экземпляра.
4.  **Расширение файлов:** Если не указано иное, класс ожидает файлы с расширением `.phtml`.
